# Provenance and Publication Boundaries

## Source class

The published material in this repository is derived from verified PAI test-result evidence selected for public-safe reuse.

## Verification standard

Only terminal test outcomes that were already observed as completed and passing are represented here. Planned, queued, materialized, or running work is not represented as complete.

## Sanitization

Before publication, the material was reduced to bounded result summaries. The public version excludes credentials, private PAI internals, sensitive logs, host-specific details, internal filesystem paths, proprietary implementation source, and unnecessary third-party material.

## Claim discipline

A passing test is reported as a passing test. It is not promoted into claims of production readiness, security certification, complete correctness, or general reliability beyond the tested scope.

## Licensing

No repository-wide license has been granted at this time. Publication of these evidence summaries should not be interpreted as a license grant for unpublished PAI source or other private material.
