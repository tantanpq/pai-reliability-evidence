# Large-Tree Freeze Evidence Storyboard

This is a public-safe storyboard for explaining an independent evidence-freeze review.

## Frame 1: The problem

A candidate can pass review and still become ambiguous if its evidence changes before the next gate. The audience sees two boxes: reviewed candidate and later candidate, with a question mark between them.

## Frame 2: Freeze the evidence

Show a fixed evidence set with a manifest and aggregate counts. The key message is that the reviewed object must stop moving before claims are carried forward.

## Frame 3: Independent readback

Show a separate reviewer comparing an independently transferred copy against the frozen manifest. The verified example covered 5,558 files and 194,318,686 bytes with zero mismatches.

## Frame 4: Prove non-mutation

Show identical before-and-after evidence receipts and a zero-change indicator. The reviewer validates the evidence without modifying the candidate or a live environment.

## Frame 5: Keep the boundary honest

End with two separate gates: freeze integrity PASS, then physical or promotion validation still pending. A green freeze is not a green production claim.

## Public boundary

No private paths, identities, source code, raw logs, credentials, internal identifiers, or source fingerprints are included.
